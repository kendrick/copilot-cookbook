**What it is**
The governance hub inside the M365 admin center for everything Copilot: enabling or disabling by group, setting agent access policies (All / No / Specific users), tracking agent inventory and lifecycle, and choosing whether an agent is deployed to users or merely made available for them to find.

**Why it matters**
The question every CISO asks first, "who decides what agents my people can run, and can I turn one off," is answered here. This is the control plane, not a feature; point skeptical admins here before anywhere else.

**Who it's for**
AI Admins (the recommended role), Global Admins, Global Readers.

**How to access**
M365 admin center > Copilot > Control System.

**Requires**
Admin configuration. No separate license, but admin role assignment is needed.
