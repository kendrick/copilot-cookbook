**What it is**
Smaller agent-platform tweaks that don't warrant their own note but are worth knowing about.

- SharePoint Admin Agent added to help admins manage SharePoint from a conversational interface.[^1]
- Agents can now be shared directly into Teams, not just discovered via the Agent Store.[^1]
- An agent evaluation grader framework (CLI-based) shipped in May 2026 for testing agent quality before rollout.[^2]
- Agent lifecycle is moving toward policy-based management: deploy, retire, and update rules set centrally rather than per-agent.[^2]
- Preview APIs (April 2026) for agent management: Package Management API, Agent Registration API, Copilot Policy Settings API.[^2]
