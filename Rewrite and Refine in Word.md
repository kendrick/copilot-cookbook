**What it is**
Select existing text in a document and ask Copilot to rewrite or enhance it in place.

**Why it matters**
Editing prose that already exists is a different job than drafting it from nothing. This keeps the writer inside the document instead of round-tripping answers through a chat pane.

**Who it's for**
Anyone tightening tone, length, or clarity on a draft that's already down on the page.

**How to access**
Select text in the document, then choose the rewrite or enhance option from the Copilot menu.

**Requires**
Microsoft 365 Copilot (add-on) license. Not included in Copilot Chat (Basic).

## Try it
1. Select the text you want to change.
2. From the Copilot menu, choose rewrite or enhance and say how it should change (for example, "Rewrite in a more formal, professional tone").

> Example prompt: Fine tune this draft to be more concise
