**What it is**
Import data from other workbooks stored in OneDrive, SharePoint, or locally.

**Why it matters**
Cross-workbook analysis without manual copy-paste between files.

**Who it's for**
Anyone consolidating data that lives in more than one file.

**How to access**
Copilot pane in Excel.

**Requires**
Microsoft 365 Copilot (add-on) license. Not included in Copilot Chat (Basic).

## Try it
1. Open the Copilot pane in Excel.
2. Name the source workbook and the data you want to bring in.

> Example prompt: Import Q1 data from archive.xlsx
