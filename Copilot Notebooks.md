**What it is**
A persistent reference library that pulls chats, uploaded files, Pages, and meeting notes into one grounded workspace.[^1]

**Why it matters**
Copilot's answers depend on what it can see. A Notebook gives a recurring project a fixed set of sources to ground against, so every chat inside it draws on the same material instead of starting over each time. A three-column layout update in June 2026 put the sources, chat, and reference panes side by side.[^2]

**Who it's for**
Anyone with a Copilot or Copilot Chat license working on a project that spans multiple files, meetings, or conversations over time.

**How to access**
Microsoft 365 Copilot app or OneNote.

**Requires**
Copilot or Copilot Chat license + SharePoint/OneDrive.
