**What it is**
The low-code, pro-developer step up from Agent Builder, for declarative agents that need more depth, or fully custom-engine and autonomous agents. Connects to 1,000+ data sources and services, supports flows, and deploys across multiple channels.

**Why it matters**
Agent Builder covers the "ask questions of a document" case. Copilot Studio covers the case where an agent needs to take action across systems: trigger a workflow, write back to a CRM, orchestrate a multi-step process. Knowing which tool the ask actually needs avoids over- or under-building.

**Who it's for**
IT, citizen developers, and makers building agents with real integration or autonomy requirements.

**How to access**
Copilot Studio (separate app/portal from the Copilot Chat experience).

**Requires**
A Copilot Studio license.
