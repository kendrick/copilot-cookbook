**The ask**
A vague review helps no one and a biased one does harm. Ground the draft in the actual work, goals, project files, notes, rather than end-of-year memory, then pressure-test the language before it goes to the employee.

**What you'll use**
- [Ground a Draft on Your Files](../Surfaces/Word/Ground%20a%20Draft%20on%20Your%20Files.md) — drafts in Word against the year's real artifacts via "/"
- [Coaching Agents](../Surfaces/Agents%20%26%20Agent%20Builder/Coaching%20Agents.md) — the Writing and Career coaches review tone, specificity, and fairness

**Steps**
1. Gather the goals document and the concrete evidence, project summaries, shipped work, notes.
2. In Word, "/" reference those files and draft the review against specific examples.
3. Run the draft past a coaching agent for tone, balance, and loaded language.
4. Revise, and make sure every judgment traces to something real.

**Prompts**
```
Draft a performance review for Jordan using /goals-2026.docx and
/Q3-project-summary.docx. Cite specific examples and keep the tone balanced.
```
```
Review this performance review for fairness. Flag anything vague, one-sided,
or that reads as personal rather than about the work.
```

**Watch out for**
The manager owns the judgment here. Copilot drafts from what you point it at, so the review is only as fair as the evidence you feed it, and only as accurate as your read of it. Ground a Draft needs the add-on; the coaching agents are free on Basic. To rehearse delivering it, see the hard-conversation recipe below.
