**What it is**
Federated connectors that link third-party data sources into Copilot using the Model Context Protocol, making outside content available in Chat, Researcher, and Excel Agent Mode.[^1]

**Why it matters**
Copilot is only as useful as the data it can reach. Connectors extend that reach to systems Microsoft doesn't natively index, using MCP as a common standard so more sources can plug in over time instead of requiring a bespoke integration for each one.

**Who it's for**
Admins connecting line-of-business systems, and end users of Chat, Researcher, and Excel Agent Mode who then get grounded answers from those systems.

**How to access**
Configured by an admin. Once connected, sources appear in Chat, Researcher, and Excel Agent Mode.

**Requires**
Admin setup per connector, plus access to the underlying system.
