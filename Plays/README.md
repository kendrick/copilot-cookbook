# Plays MOC

Scenario-first recipes, grouped by the business need a user would state out loud. When someone says "I need to *do* X," start here. Each play chains the features that get it done, with copy-pasteable prompts.

For the capability reference behind these, see the [[Copilot Features MOC]].

## Analyze data

- [[Draft an Excel Pivot From a Chat-Generated Prompt]] — have Chat write the Excel prompt, then run it
- [[Find the Story in a Messy Spreadsheet]] — point Analyst at raw data and get trends, outliers, a summary
- [[Weigh Options From Long Documents]] — compare vendors, filings, or contracts across many files

## Catch up on what I missed

- [[Catch Up After Time Away]] — one prompt across email and Teams to rebuild context after PTO
- [[Get the Gist of a Meeting You Missed]] — the recap, decisions, and action items without rewatching
- [[Summarize a Thread Before You Reply]] — the state of a long email chain in seconds

## Draft from messy inputs

- [[Turn Meeting Notes Into a Project Brief]] — raw notes to a structured brief
- [[Blend Two Job Descriptions Into One]] — merge role profiles into a single posting
- [[Draft a Sensitive Email That Lands Well]] — draft, then coach for tone before you send

## Prep for a meeting

- [[Prep for a Customer Call]] — research the account and surface the questions to ask
- [[Build a Copilot Notebook for a Recurring Project Status]] — a reusable workspace that generates the status

## Build a deck

- [[Turn a Report Into a Deck]] — a long document becomes a slide deck
- [[Build a Deck From Your Work Content]] — let Copilot gather the files, meetings, and mail for you

## Automate a recurring task

- [[Stand Up a No-Code Team Agent]] — an agent your team can ask, built without code
- [[Schedule a Recurring Status Digest]] — a prompt that runs itself on a cadence
- [[Hand a Multi-Step Task to Cowork]] — delegate a whole workflow, approve each step

## Research a topic

- [[Run a Deep Research Brief]] — a cited, structured report from the Researcher agent
- [[Scan the Market With Chat]] — a fast web-grounded read on a topic or competitor
