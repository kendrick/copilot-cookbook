# Plays MOC

Scenario-first recipes, grouped by the business need a user would state out loud. When someone says "I need to *do* X," start here. Each play chains the features that get it done, with copy-pasteable prompts.

For the capability reference behind these, see the [Copilot Features MOC](../Surfaces/README.md).

## Analyze data

- [Draft an Excel Pivot From a Chat-Generated Prompt](Draft%20an%20Excel%20Pivot%20From%20a%20Chat-Generated%20Prompt.md) — have Chat write the Excel prompt, then run it
- [Find the Story in a Messy Spreadsheet](Find%20the%20Story%20in%20a%20Messy%20Spreadsheet.md) — point Analyst at raw data and get trends, outliers, a summary
- [Weigh Options From Long Documents](Weigh%20Options%20From%20Long%20Documents.md) — compare vendors, filings, or contracts across many files

## Catch up on what I missed

- [Catch Up After Time Away](Catch%20Up%20After%20Time%20Away.md) — one prompt across email and Teams to rebuild context after PTO
- [Get the Gist of a Meeting You Missed](Get%20the%20Gist%20of%20a%20Meeting%20You%20Missed.md) — the recap, decisions, and action items without rewatching
- [Summarize a Thread Before You Reply](Summarize%20a%20Thread%20Before%20You%20Reply.md) — the state of a long email chain in seconds

- [Turn Meeting Notes Into a Project Brief](Turn%20Meeting%20Notes%20Into%20a%20Project%20Brief.md) — raw notes to a structured brief
