**What it is**
A no-code way to build a declarative agent by describing it in plain language and pointing it at knowledge sources: SharePoint, Teams, OneDrive, uploaded files, or the web. OneDrive sources cap at 50 files. Templates and a default response mode cover the common cases without extra setup.

**Why it matters**
Not every recurring task needs a developer. If someone keeps re-asking the same question of the same handful of documents, that's a five-minute agent, not a ticket to IT.

**Who it's for**
Business users and power users who want a scoped, knowledge-grounded assistant without writing code.

**How to access**
Copilot Chat > Agents > **Create an agent**, or start from a template.

**Requires**
Copilot add-on, or Copilot Chat pay-as-you-go, or a Copilot Studio license. For agents that need to act autonomously or reach beyond declarative Q&A, step up to [[Copilot Studio]].
