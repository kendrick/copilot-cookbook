**What it is**
Reference up to 20 files, emails, or meetings as source material for a draft by typing "/" in the Copilot box.

**Why it matters**
A draft grounded on real source material needs far less fact-checking and rewriting than one built from a bare prompt.

**Who it's for**
Anyone turning existing material—a meeting, a set of emails, a batch of reports—into a new document.

**How to access**
In the Copilot box, type "/" to reference files, emails, or meetings (up to 20 sources).

**Requires**
Microsoft 365 Copilot (add-on) license. Not included in Copilot Chat (Basic).

## Try it
1. In the Copilot box, type "/" and pick the file, email, or meeting to reference.
2. Describe the draft you want built from that source.

> Example prompt: Write a proposal for a new flavor using /New flavor research.docx
