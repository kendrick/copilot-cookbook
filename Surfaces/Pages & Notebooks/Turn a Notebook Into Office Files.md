**What it is**
Generate a PowerPoint, Word, or Excel file directly from a Notebook's content and reference sources.[^1]

**Why it matters**
A Notebook already holds the grounded context for a project. This turns that context into a deliverable directly, instead of making you export the raw contents and rebuild a deck or doc by hand.

**Who it's for**
Anyone using Notebooks for a recurring project who needs to turn accumulated notes into a shareable artifact: a status deck, a project brief, a tracking workbook.

**How to access**
From within a Notebook in the Microsoft 365 Copilot app.

**Requires**
Copilot or Copilot Chat license + an existing Notebook with content and references.
