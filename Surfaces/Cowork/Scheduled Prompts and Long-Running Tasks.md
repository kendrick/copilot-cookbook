**What it is**
Schedule a recurring prompt to run against an agent automatically, and track long-running agent tasks, including Cowork jobs, from the Windows taskbar.[^1]

**Why it matters**
Agentic work doesn't finish instantly. Scheduling turns a one-off prompt into a standing routine, like a weekly digest or a recurring status pull, and taskbar visibility means you don't need to keep a browser tab open to know when a long-running task finishes.

**Who it's for**
Anyone running recurring reporting or monitoring tasks through Cowork or other agents.

**How to access**
Schedule from the agent's prompt interface; monitor task status from the Windows taskbar.

**Requires**
Copilot add-on; an agent configured to accept scheduled prompts.
