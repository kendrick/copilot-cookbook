**What it is**
Every SharePoint site comes with a ready-made agent scoped to that site's content. Users with edit permissions can also build custom agents pointed at specific pages or libraries. Both answer questions, summarize, and analyze documents, and both stay inside each user's existing permissions.[^1]

**Why it matters**
A team site is usually a filing cabinet nobody reads all the way through. The ready-made agent turns the site into something you ask instead of scroll, and it's there by default with nothing to configure. A custom agent narrows that down to the exact library that holds the answer.

**Who it's for**
Site visitors who need an answer from a site's content, and site owners or editors who want a curated agent grounded on a chosen source.

**How to access**
Visit any SharePoint site to use its ready-made agent. To build a custom one, use the site interface: name the agent, choose its sources, and describe how it should behave.

**Requires**
A Microsoft 365 Copilot license, or a pay-as-you-go plan for SharePoint agents where the org has enabled it. Ready-made agents can't be edited or shared, and admins can remove them via the Restricted Content Discovery policy.

## Try it
1. Open a SharePoint site and select its ready-made agent.
2. Ask a question about the site's content.

> Example prompt: Give me an overview of the Mega-300 product from the material on this site.[^1]
