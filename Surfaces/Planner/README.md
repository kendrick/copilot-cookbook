Planner is where the work a meeting generates actually lands. Copilot here builds a plan from a description, and the Planner Agent keeps it moving: generating tasks from goals, writing status reports off the plan's own data, and taking on tasks you assign it.

- [Copilot in Planner](Copilot%20in%20Planner.md) — chat that drafts a full plan of tasks, buckets, and goals
- [Planner Agent](Planner%20Agent.md) — an agent that generates tasks, reports status, and executes assigned work
