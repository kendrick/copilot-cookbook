**What it is**
An agent embedded in Planner (also called the Project Manager agent) that generates task lists from goals, writes status reports off the plan's own data, and takes on tasks you assign it. Its output surfaces in Loop components.[^1]

**Why it matters**
Status reporting is the recurring tax on running a plan: the same pull-the-highlights job, every week. Handing that to an agent that reads the plan directly turns a Friday chore into a prompt.

**Who it's for**
Project managers and plan owners who want task generation and status tracking handled rather than hand-assembled.

**How to access**
On a basic plan, use the floating action button in the bottom-right of a plan. On a premium plan shared with a Microsoft 365 Group, the agent is enabled by default.[^2]

**Requires**
A Microsoft 365 Copilot license. Premium Planner tiers (Planner Plan 1, or Planner and Project Plan 3 or 5) unlock the advanced capabilities, including automatic task generation from goals and status reports, which need at least 10 tasks on the plan. The plan must be shared with a Microsoft 365 Group.
