**What it is** — Copilot in Loop could summarize a page and draft or add content. Microsoft has since removed those integrations "to synchronize with Microsoft 365 Copilot Pages."

**Why it matters** — Loop's Copilot support is mid-transition. Treat any prior documentation of Loop-specific steps as stale, and expect the functionality to resurface through [Copilot Pages](../Pages%20%26%20Notebooks/Copilot%20Pages.md) rather than Loop itself.

**Who it's for** — Loop users, though current capability is in flux.

**How to access** — Not currently documented — the prior integration was removed and hasn't been replaced with published steps yet.

**Requires** — Copilot add-on license plus Microsoft 365 E3/E5.
