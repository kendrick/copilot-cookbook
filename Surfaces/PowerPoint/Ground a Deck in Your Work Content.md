**What it is**
PowerPoint's Agent Mode auto-gathers relevant files, meetings, and emails to ground a deck in a team's actual work content, powered by Work IQ.

**Why it matters**
A deck grounded in real source material—a report, a meeting, an email thread—needs far less manual assembly than one built from a bare prompt.

**Who it's for**
Anyone turning existing work product into a presentation.

**How to access**
Agent Mode in PowerPoint. The capability started as a preview for adding slides directly from files; the fuller work-content grounding described here reached general availability in July 2026.

**Requires**
Microsoft 365 Copilot (add-on) license. Not included in Copilot Chat (Basic).
