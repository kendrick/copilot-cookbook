**What it is**
Copilot builds a new presentation from a prompt or an existing Word file, asking clarifying questions along the way (Agent Mode). It can start from an organization's own template to stay on-brand, and new presentations can also be created from the web at m365.cloud.microsoft.

**Why it matters**
A blank deck becomes a working starting point in minutes, on-brand by default, instead of a blank canvas someone has to structure from scratch.

**Who it's for**
Anyone building a first draft of a deck from notes, a report, or a prompt.

**How to access**
Start a new presentation in PowerPoint, or create one at m365.cloud.microsoft.

**Requires**
Microsoft 365 Copilot (add-on) license. Not included in Copilot Chat (Basic). Length, tone, and style controls are rolling out to Frontier/Insiders first.

## Try it
1. Start a new presentation in PowerPoint, or create one at m365.cloud.microsoft.
2. Describe the deck you want, then answer any clarifying questions Copilot asks.

> Example prompt: Create a presentation about Q3 financial results for the board of directors. Include revenue trends, expense analysis, and forecast. Use a professional tone with minimal jargon.
