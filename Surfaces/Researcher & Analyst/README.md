# Researcher & Analyst

Two reasoning agents that go beyond a chat answer and do actual multi-step work. [Researcher](Researcher.md) investigates a question across your work content and the web, then hands back a source-cited report. [Analyst](Analyst.md) runs visible Python against data you give it and comes back with stats, trends, and charts. Both went GA the same day, both require the add-on license, and both draw from one shared pool of roughly 25 monthly queries—worth knowing before someone burns through their quota on the wrong agent.[^1]
