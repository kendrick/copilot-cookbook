**What it is**
A reasoning agent that runs visible Python against data you upload, surfacing stats, trends, outliers, and charts. Powered by OpenAI's o3-mini reasoning model. GA since June 2025.[^1]

**Why it matters**
"Visible Python" is the detail worth repeating to a skeptical stakeholder: Analyst doesn't just assert a trend, it shows the code that found it, which is a meaningfully different trust proposition than a chat answer that states a number and moves on.

**Who it's for**
Anyone running statistical analysis on a dataset—survey results, marketing performance data, financial reports—who wants visible working, not just a conclusion.

**How to access**
Microsoft 365 Copilot app > Agents > Analyst.[^1]

**Requires**
Microsoft 365 Copilot add-on license. Shares a combined pool of roughly 25 monthly queries with [Researcher](Researcher.md).

## Try it
1. Open the Microsoft 365 Copilot app.
2. Go to Agents > Analyst.
3. Upload a dataset and ask for patterns or a summary.

Example prompt:
> Analyze this survey data and generate strategic recommendations, flagging any statistically significant trends.[^2]
