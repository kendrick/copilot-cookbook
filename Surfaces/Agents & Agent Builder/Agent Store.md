**What it is**
A catalog for discovering and installing agents built by Microsoft, by partners, or by your own org, without leaving the flow of work.

**Why it matters**
Most people won't build an agent from scratch, but they will use one someone else already built. The Agent Store is how a well-built internal agent (say, a policy Q&A bot one team stood up) reaches everyone else, instead of staying known only to its creator.

**Who it's for**
Any Copilot user browsing for a ready-made agent, and admins curating which agents are visible to whom.

**How to access**
- M365 Copilot app > **Agents** > **All agents**
- Teams > **Copilot** > **All agents**

**Requires**
Copilot Chat (Basic), available broadly, though admins can gate specific agents via Copilot Control System.
