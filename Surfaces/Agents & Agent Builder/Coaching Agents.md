**What it is**
A set of prebuilt Microsoft agents aimed at improving how you work, not just what you produce: Writing Coach, Idea Coach, Prompt Coach, Career Coach, and Learning Coach. A related Facilitator agent supports running meetings.

**Why it matters**
These ship inside Copilot Chat at no add-on cost, so they're a low-friction entry point for new users. Prompt Coach in particular is worth pointing skeptical users at, since "I don't know how to prompt this thing" is one of the more common adoption blockers.

**Who it's for**
Any Copilot Chat user; particularly useful for skill development (writing, career growth, learning) rather than task output.

**How to access**
Copilot Chat > **Agents**. Coaching agents appear alongside other prebuilt agents, no setup required.

**Requires**
Copilot Chat (Basic), no add-on needed.
