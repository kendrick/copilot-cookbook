Agents are how Copilot moves from "answer my question" to "handle this recurring thing for me." This category covers where agents come from and what you can build without writing code.

- [Agent Store](Agent%20Store.md): discover and install agents built by Microsoft, partners, or your own org.
- [Agent Builder](Agent%20Builder.md): no-code creation of a declarative agent from plain language and your own knowledge sources.
- [Coaching Agents](Coaching%20Agents.md): prebuilt agents (Writing, Idea, Prompt, Career, Learning Coach) included at no add-on cost.
- [Copilot Studio](Copilot%20Studio.md): the low-code step up for custom or autonomous agents that need to act across systems.
- [Minor Updates — Agents](Minor%20Updates%20%E2%80%94%20Agents.md): smaller platform tweaks worth knowing about.
