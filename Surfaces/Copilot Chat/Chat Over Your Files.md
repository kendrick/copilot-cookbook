**What it is**
Upload a file directly into a Copilot Chat conversation and ask questions grounded in its content. Included on Basic; add-on licenses get priority processing.[^1]

**Why it matters**
Not every question needs a document opened in edit mode. Sometimes you just want an answer out of a PDF or spreadsheet without leaving the chat window, and this is the fastest path there.

**Who it's for**
Anyone with Copilot Chat access, Basic or add-on.

**How to access**
Attach a file to the Copilot Chat conversation, then ask about it. Available on both tiers.[^1]

**Requires**
Any Microsoft 365 subscription for Basic access, or the Copilot add-on for priority processing.
