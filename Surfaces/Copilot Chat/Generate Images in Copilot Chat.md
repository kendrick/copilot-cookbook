**What it is**
Generate images directly inside a Copilot Chat conversation, powered by Copilot's built-in Designer integration. Included on Basic; add-on licenses get priority processing.[^1]

**Why it matters**
No separate tool, no context switch. This is for a quick concept image mid-conversation, not a polished deck asset—for that, see [[Generate Images in PowerPoint]] and [[Brand Kit for Visuals]].

**Who it's for**
Any Copilot Chat user who needs a quick visual rather than a production-ready one.

**How to access**
Ask Copilot Chat to generate an image, on either tier.

**Requires**
Any Microsoft 365 subscription, or the Copilot add-on for priority processing.
