**What it is**
The free tier of Copilot Chat, included with any Microsoft 365 subscription. Answers are grounded in the open web rather than your organization's Graph data, and requests run at standard, capacity-limited access.[^1]

**Why it matters**
Basic is how most employees meet Copilot before anyone buys them a seat, so it sets the baseline expectation for the tool. Worth knowing before you coach someone who's judging the add-on by what Basic already does.

**Who it's for**
Every Microsoft 365 user, licensed or not. This is what shows up by default.

**How to access**
Copilot chat is available in Outlook and Teams for Basic users. There's no in-app Copilot inside Word, Excel, PowerPoint, or OneNote on this tier.[^1]

**Requires**
Any Microsoft 365 subscription. No Copilot add-on license needed.

## Try it
1. Open Copilot Chat in Outlook or Teams.
2. Ask a general-knowledge or web-research question.

Example prompt:
> Summarize the main points of the latest research on AI.[^2]
