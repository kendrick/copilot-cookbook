**What it is**
Three response modes in Copilot Chat: Auto, which routes each prompt to whichever model fits it best; Quick response, for fast answers; and Think Deeper, for slower, more thorough reasoning on hard questions. GA on both Basic and add-on tiers.[^1]

**Why it matters**
Most people never touch this and just let Auto decide, which is usually fine. But it's worth knowing Think Deeper exists for the moment someone gets a shallow answer to a genuinely hard question—often the fix isn't a better prompt, it's a different mode.

**Who it's for**
Any Copilot Chat user who wants control over the speed-versus-depth tradeoff.

**How to access**
Select a mode from the model picker in the Copilot Chat composer, on either tier.

**Requires**
Any Microsoft 365 subscription, or the Copilot add-on.
