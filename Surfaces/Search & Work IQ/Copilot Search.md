**What it is**
Semantic, universal search across Microsoft 365 content and 100+ connected third-party systems, including Salesforce, ServiceNow, Confluence, Jira, GitHub, and Google Drive, from one search surface.[^1]

**Why it matters**
Enterprise knowledge rarely lives in a single tenant's file system. Copilot Search closes the gap between searching your own files and searching everything you're entitled to see, matching on meaning rather than exact keywords, so a query can surface the right document even when it doesn't contain the literal search term.

**Who it's for**
Anyone on the Copilot add-on tier who needs to find information scattered across M365 and connected line-of-business systems.

**How to access**
Microsoft 365 Copilot app > Search.

**Requires**
Copilot add-on license. Connectors for third-party sources need to be configured by an admin.
