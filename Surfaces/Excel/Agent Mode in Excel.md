**What it is**
Plan mode: Copilot proposes a multi-step plan for a task and waits for approval before making changes.

**Why it matters**
Multi-step spreadsheet work—restructuring, cleanup, multi-formula builds—becomes reviewable before it touches the file, instead of an all-at-once transformation you have to undo if it's wrong.

**Who it's for**
Anyone handing Copilot a bigger, multi-step task rather than a single formula or chart.

**How to access**
Plan mode in the Excel Copilot pane.

**Requires**
Microsoft 365 Copilot (add-on) license. Not included in Copilot Chat (Basic).
